# Exploratory Data Analysis - Titanic Dataset

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to uncover patterns, trends, correlations, and key factors that influenced passenger survival.

The analysis uses statistical summaries and data visualizations to understand the dataset and generate meaningful insights.

## 🎯 Objectives

- Understand and explore the Titanic dataset
- Generate statistical summaries
- Identify missing and duplicate values
- Analyze numerical variables
- Study correlations between variables
- Identify factors influencing passenger survival
- Visualize important patterns and trends
- Present data-driven insights and conclusions

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 📊 Dataset

The Titanic dataset contains information about passengers, including:

- Passenger class
- Gender
- Age
- Fare
- Survival status
- Other passenger-related information

## 🔍 EDA Performed

### 1. Dataset Exploration
- First and last rows
- Number of rows and columns
- Column names
- Dataset information

### 2. Statistical Analysis
- Descriptive statistics
- Mean values
- Survival rates
- Numerical variable analysis

### 3. Data Quality Analysis
- Missing value detection
- Duplicate row detection
- Unique value analysis

### 4. Data Visualization
The following visualizations were created:

- Histograms
- Box plots
- Count plots
- Correlation heatmap
- Age distribution by survival
- Fare distribution by survival

### 5. Survival Analysis

Survival was analyzed based on:

- Gender
- Passenger class
- Age
- Fare

## 📈 Key Insights

The analysis shows that:

- Passenger survival rates differed significantly between genders.
- Passenger class had an important relationship with survival.
- Survivors and non-survivors showed differences in average age.
- Survivors generally showed differences in average fare compared with non-survivors.
- Correlation analysis helped identify relationships between numerical variables.
